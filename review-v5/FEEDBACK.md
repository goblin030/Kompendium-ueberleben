# Review-Feedback v5 (Projektowner, 2026-11-07)

## Anforderungen an Checklisten

1. **Checklisten ans Ende jedes Bandes verschieben** — nicht mehr mitten im Kapitel,
   sondern gesammelt in einem Checklisten-Anhang am Bandende.
2. **Identifizierbar über Bezeichnung + Kennziffer** — jede Checkliste bekommt eine
   eindeutige Kennziffer (z. B. `CL-B1-01`) + sprechende Bezeichnung; im Text nur noch
   Querverweise auf die Kennziffer („siehe CL-B1-03, Bandanhang“).
3. **Begriffserläuterung pro Checkliste** — jede Checkliste enthält ein Mini-Glossar /
   Erläuterung der verwendeten Fachbegriffe (Begriffe sind nicht immer selbsterklärend).

## Routing

| Anforderung | Agent |
|---|---|
| Checklisten ans Bandende, Kennziffern CL-Bn-NN, Querverweise, Begriffserläuterungen | editor (Turn 7) |
| Checklisten-Register (Kennziffer → Band/Seite) ins Gesamtregister | index-builder (Turn 2) |
| Rebuild mit Anhang + aufgelösten Querverweisen, visual-qa Re-Run | doc-builder (Turn 11), visual-qa (Turn 3) |
